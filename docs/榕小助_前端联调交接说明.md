## 1. 环境准备

### 1.1 后端

```bash
cd xiaozhu_backend
pip install -r ../requirements.txt
# 配置 .env（MySQL），见 README.md
python manage.py migrate
python manage.py seed_test_users
daphne xiaozhu_backend.asgi:application -b 0.0.0.0 -p 8000
```


| 步骤                | 说明                                               |
| ----------------- | ------------------------------------------------ |
| `migrate`         | 建表；若旧库缺列，会应用 `0002_visitrecord_duration_seconds` |
| `seed_test_users` | **零数据环境必跑**，可重复执行                                |
| `daphne`          | 走访转写 WebSocket 需要；仅测登录可用 `runserver`             |


### 1.2 走访全链路（可选）

上传 / 转写 / WebSocket 还需：

- MinIO（bucket `xiaozhu`）
- Redis（Channels）

详见 `API_DOC.md` 中 MinIO / Redis 启动说明。

## 4. 认证与请求约定

1. `POST /api/auth/login/` → 保存 `token`、`refreshToken`（refresh）、`userInfo` 到本地
2. 业务请求（`/api/file/*`）由 `api/request.js` 自动加：`Authorization: Bearer <token>`
3. **不要**在业务接口传 `creator_id`，用户身份由 JWT 解析
4. 401 → 清本地登录态并跳转登录页
5. App 冷启动：有 token 时调 `GET /api/auth/me/` 校验并刷新 `userInfo`

相关代码：

- 登录：`xiaozhu_frontend/api/login.js`
- 请求封装：`xiaozhu_frontend/api/request.js`
- 走访 API：`xiaozhu_frontend/api/file.js`

## 5. 接口一览


| 接口                   | 方法   | 说明                                 |
| -------------------- | ---- | ---------------------------------- |
| `/api/auth/login/`   | POST | 登录，Body: `{"username","password"}` |
| `/api/auth/me/`      | GET  | 验 token + 当前用户                     |
| `/api/auth/refresh/` | POST | Body: `{"refresh"}`                |
| `/api/auth/logout/`  | POST | MVP 以前端清 token 为主                  |
| `/api/file/*`        | POST | 需 Bearer token，参数见 API_DOC         |

## 7. 常见问题


| 现象               | 处理                                           |
| ---------------- | -------------------------------------------- |
| 登录一直失败           | 是否执行 `seed_test_users`；MySQL `.env` 是否正确     |
| 业务接口 401         | 是否先登录；token 是否过期；Header 是否为 `Bearer <token>` |
| 上传失败 / MinIO 错误  | 启动 MinIO 并创建 bucket `xiaozhu`                |
| 转写 WebSocket 连不上 | 用 daphne 启动；Redis 是否运行                       |
| 真机连不上后端          | `config.js` 改为电脑局域网 IP，手机与电脑同网段              |
| H5 跨域            | 确认后端 CORS 或走 manifest 代理                     |
