# 榕小助 APP 需求对接材料准备清单

为确保系统设计与实际业务场景深度契合，并顺利推进后续开发工作，请业务需求方协助准备以下五类核心业务材料。这些材料将直接决定AI大模型的输出质量以及系统权限控制的准确性。

## 1. 业务语料与知识库素材（用于AI智能体训练）
- **政策与业务文档**：最新的资费标准、营销方案、重要通知历史文件（建议提供 Word、PDF 或 Markdown 格式）。
- **常见问答（FAQ）**：客户经理在日常走访中常问的高频问题及标准话术。
- **业务实体清单**：如常见的宽带套餐名称、专线类型、行业专有名词表，用于提升AI语音识别（ASR）的准确率。

## 2. 走访与待办业务规范（用于AI总结与表单设计）
- **历史走访纪要样例**：提供 3-5 份人工记录的优秀走访纪要，以便我们调试AI总结的Prompt（提示词），使其输出格式符合现有工作习惯。
- **关键信息提取要素**：明确在走访结束后，AI必须从录音中提取哪些关键字段（例如：客户意向等级、办理业务类型、预约回访时间等）。
- **待办事项分类**：梳理常见的待办任务类型（如：查资源、开票、催欠），及期望的闭环流转状态。

## 3. 组织架构与权限矩阵（用于通知分发与审批流）
- **人员角色清单**：明确各岗位的具体定义与系统权限范围（如：客户经理、商客经理、网格长、区县7岗、市公司8岗等）。
- **通知额度与审核规则矩阵**：
  - 各层级（网格、区县、市公司）每月的通知发送额度。
  - 矩阵审核的具体流转节点（如：超出额度时，从发起人到8岗审批的完整路径）。
- **管理层级映射关系**：明确网格与区县、区县与市公司的从属及汇报关系。

## 4. 现有系统与接口信息（用于系统集成）
- **统一认证（SSO）对接文档**：如需与移动公司现有的统一门户或OA系统进行单点登录，请提供相关API文档或对接人联系方式。
- **内部系统数据接口**：若待办事项需要推送到现有CRM系统，或从现有系统拉取客户数据，请提供相关接口规范。

## 5. 硬件联动与安全合规要求（用于拓展规划）
- **智能硬件参数（如有）**：关于计划配套的物联网工牌，目前是否有已选型的硬件设备？需提供其蓝牙通信协议或API对接文档。
- **安全审计标准**：移动公司内部对于APP录音留存、数据加密传输及落地的具体安全规范与合规要求。
